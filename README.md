# Eve 楽曲イントロクイズ (Official Songs & YouTube Music Intro Quiz)

アーティスト **Eve** さんの名曲だけで遊べる本格的なイントロクイズゲームです。
ブラウザ内蔵の **SQLite データベース (WebAssembly / sql.js)** を活用し、出題曲の選定、難易度別フィルタリング、過去のスコア履歴や回答ログの保存、さらにはブラウザ上でのリアルタイムSQLコンソールまで搭載しています。

---

## 🎮 主な機能と特徴 (最新アップデート)

- **3段階の再生コントロールボタン（何度でも無制限に聴き直し可能！）**
  - **🎵 最初の一秒 (0:00〜)**: 冒頭の一瞬（1.0秒 / 鬼0.4秒 / 神0.1秒）を再生。
  - **⚡ 0:05〜 を流す**: 冒頭の無音やロゴをスキップし、5秒目から指定秒数を再生。
  - **🔥 1:00〜 を流す (サビ前)**: 60秒地点（サビ前〜盛り上がり部分）から再生。イントロで分からなくてもサビで判別可能！
  - **制限時間無制限**: カウントダウンによる強制終了を廃止し、じっくり思考して回答できます。

- **選べる5つの難易度（超極限の「0.1秒モード」搭載！）**
  1. **EASY (初級)**: イントロ **5.0秒** 再生 / 定番曲中心 / 発売年・アルバムのヒント付き
  2. **NORMAL (中級)**: イントロ **2.5秒** 再生 / 人気曲・アルバム曲から出題
  3. **HARD (上級)**: イントロわずか **1.0秒** 再生 / アルバム曲・YouTube Music公式音源含む全55曲から出題
  4. **鬼 (DEMON)**: 極限の **0.4秒** イントロドン！ / マイナー曲・アルバム曲の出現確率アップ
  5. **神 (GOD 0.1秒)**: **超絶極限の 0.1秒（100ms）イントロドン！** 音が鳴った瞬間に物理ミュート＆ストップする究極の神領域モード（スコア倍率 6.0x）

- **Eveさんの名曲・アルバム曲 全55曲を完全収録！**
  - **公式MV楽曲**: 『廻廻奇譚』『ドラマツルギー』『ナンセンス文学』『お気に召すまま』『僕らまだアンダーグラウンド』『レーゾンデートル』『ファイトソング』『ぼくらの』『花嵐』『ティーンエイジブルー』『インソムニア』『白雪』『Glorious』『さよならエンドロール』『巻物語』『フラットウッズのモンスターみたいに』など
  - **『心海』の公式アニメーションMV対応**: まりやす氏制作の公式MV（`vRPCAAUBMms`）
  - **YouTube Music公式音源（アルバム名曲・コアファン必聴曲）**:
    - 『ふりをした。』『会心劇』『羊を数えて』『ホームシック』 (アルバム『文化』)
    - 『迷い子』『やどりぎ』 (アルバム『おとぎ』)
    - 『胡乱な食卓』『mellow』 (アルバム『Smile』)
    - 『言の葉』 (アルバム『廻人』) など、MVのない隠れた名曲も公式配信音源で完全網羅！

- **本格的な SQLite データベース搭載**
  - 楽曲テーブル (`songs`: 全55曲, `source_type` 列追加)、難易度テーブル (`difficulties`: 全5段階)、プレイ履歴 (`play_history`)、回答ログ (`answer_logs`) を内蔵
  - IndexedDB と連動し、ブラウザをリロードするだけで自動マイグレーションを実行
  - **SQLコンソール内蔵**: ゲーム画面内で任意の `SELECT` 文を実行して集計や検索が可能

## 🚀 起動方法

### 方法1: バッチファイルから起動（おすすめ）
フォルダ内の **`start_game.bat`** をダブルクリックするだけで、ローカルサーバーが立ち上がり、自動でブラウザが開きます。

### 方法2: PowerShell から起動
PowerShell を開き、以下のコマンドを実行します：
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
起動後、ブラウザで [http://localhost:8080/](http://localhost:8080/) にアクセスしてください。
