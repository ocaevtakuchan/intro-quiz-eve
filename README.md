# Eve 楽曲イントロクイズ (Official Songs & YouTube Music Intro Quiz)

アーティスト **Eve** さんの名曲だけで遊べる本格的なイントロクイズゲームです。
ブラウザ内蔵の **SQLite データベース (WebAssembly / sql.js)** を活用し、出題曲の選定、難易度別フィルタリング、過去のスコア履歴や回答ログの保存、さらにはブラウザ上でのリアルタイムSQLコンソールまで搭載しています。

---

## 🎮 主な機能と特徴 (最新アップデート)

- **何度でも聴き直し可能 & 制限時間「無制限」！**
  - **「🔄 もう一度聴く」機能が無制限**: 何回でも納得いくまでイントロをリプレイできます。
  - **制限時間無制限**: カウントダウンによる強制終了を廃止し、じっくり思考して回答できます（早期回答ボーナスも付与）。
  - **高精度ストップ**: ハード（1.0秒）やデーモン（0.4秒）でも、音が鳴り始めてから正確に指定秒数でピタッと停止。

- **Eveさんの名曲・アルバム曲 全55曲を完全収録！**
  - **公式MV楽曲**: 『廻廻奇譚』『ドラマツルギー』『ナンセンス文学』『お気に召すまま』『僕らまだアンダーグラウンド』『レーゾンデートル』『ファイトソング』『ぼくらの』『花嵐』『ティーンエイジブルー』『インソムニア』『白雪』『Glorious』『さよならエンドロール』『巻物語』『フラットウッズのモンスターみたいに』など
  - **『心海』の公式アニメーションMV対応**: まりやす氏制作の公式MV（`vRPCAAUBMms`）に更新済み！
  - **YouTube Music公式音源（アルバム名曲・コアファン必聴曲）**:
    - 『ふりをした。』『会心劇』『羊を数えて』『ホームシック』 (アルバム『文化』)
    - 『迷い子』『やどりぎ』 (アルバム『おとぎ』)
    - 『胡乱な食卓』『mellow』 (アルバム『Smile』)
    - 『言の葉』 (アルバム『廻人』) など、MVのない隠れた名曲も公式配信音源で完全網羅！

- **選べる4つの難易度**
  1. **EASY (初級)**: イントロ **5.0秒** 再生 / 定番曲中心 / 発売年・アルバムのヒント付き / 何度でも聴き直しOK
  2. **NORMAL (中級)**: イントロ **2.5秒** 再生 / 人気曲・アルバム曲から出題 / 何度でも聴き直しOK
  3. **HARD (上級)**: イントロわずか **1.0秒** 再生 / アルバム曲・YouTube Music公式音源含む全55曲から出題 / 何度でも聴き直しOK
  4. **鬼 (DEMON)**: 極限の **0.4秒** イントロドン！ / マイナー曲・アルバム曲の出現確率が大幅アップ / 何度でも聴き直しOK

- **本格的な SQLite データベース搭載**
  - 楽曲テーブル (`songs`: 全55曲, `source_type` 列追加)、難易度テーブル (`difficulties`)、プレイ履歴 (`play_history`)、回答ログ (`answer_logs`) を内蔵
  - IndexedDB と連動し、ブラウザをリロードするだけで自動マイグレーションを実行
  - **SQLコンソール内蔵**: ゲーム画面内で任意の `SELECT` 文を実行して集計や検索が可能
  - データベースの `.sqlite` ファイルとしてのダウンロードエクスポートやリセット機能付き

## 🚀 起動方法

### 方法1: バッチファイルから起動（おすすめ）
フォルダ内の **`start_game.bat`** をダブルクリックするだけで、ローカルサーバーが立ち上がり、自動でブラウザが開きます。

### 方法2: PowerShell から起動
PowerShell を開き、以下のコマンドを実行します：
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
起動後、ブラウザで [http://localhost:8080/](http://localhost:8080/) にアクセスしてください。

## 🗄️ データベース設計

### `songs` (楽曲マスター: 全55曲)
| カラム | 型 | 説明 |
|---|---|---|
| `id` | INTEGER PRIMARY KEY | 楽曲ID (1〜55) |
| `title` | TEXT | 曲名 (例: 廻廻奇譚, 心海, ふりをした。) |
| `reading` | TEXT | ひらがな読み |
| `youtube_id` | TEXT | 公式YouTube動画ID |
| `intro_start` | REAL | イントロ開始秒数 |
| `release_year` | INTEGER | リリース年 |
| `album` | TEXT | 収録アルバム名 (文化, おとぎ, Smile, 廻人, Under Blue, OFFICIAL NUMBER 等) |
| `tier` | INTEGER | 難易度帯 (1: 定番, 2: 人気曲, 3: マイナー/アルバム曲) |
| `source_type` | TEXT | 音源種別 (`MV` または `YouTubeMusic`) |
| `trivia` | TEXT | タイアップや楽曲豆知識 |
